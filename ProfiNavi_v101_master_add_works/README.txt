ProfiNavi — версия для Netlify

Как открыть на телефоне:
1. Перейдите на https://app.netlify.com/drop
2. Войдите или зарегистрируйтесь.
3. Распакуйте ZIP ProfiNavi_Netlify_ready.zip.
4. Перетащите на страницу Netlify папку ProfiNavi_Netlify_ready целиком.
5. Netlify выдаст HTTPS-ссылку — откройте её на телефоне.

Важно:
- На главной есть компактная карта Бишкека с мастерами без запроса геолокации.
- Нажатие на карту или вкладку «Поиск» открывает полноэкранную карту.
- Геолокация запрашивается только во вкладке «Поиск».
- Для геолокации нажмите «Разрешить» в браузере телефона.
- API-ключ 2GIS MapGL уже встроен.

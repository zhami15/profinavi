PROFINAVI — версия для телефона

1. Загрузите этот ZIP целиком на Tiiny Host, Netlify Drop или Cloudflare Pages.
2. После публикации откройте полученную ссылку на телефоне.
3. На iPhone: Поделиться → На экран «Домой».
4. На Android: меню браузера → Добавить на главный экран.

Главный файл: index.html

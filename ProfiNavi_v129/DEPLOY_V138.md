# Deploy ProfiNavi v140 — clean-start compatible

## 1. Очистить и привести Supabase к v138

1. Открой Supabase → SQL Editor → New query.
2. Вставь **полное содержимое** `profinavi_v138_clean_reset_FIXED_R2.sql`.
3. Выполни запрос один раз.
4. Он должен завершиться без ошибки.

Важно: скрипт удаляет старые тестовые данные приложения. `profinavi_admin_allowlist`, Edge Functions и Storage buckets не удаляются.

## 2. Загрузить frontend

Загрузи содержимое папки `ProfiNavi_v138` в Vercel.

При первом открытии v138 сайт один раз очистит старую локальную тестовую Supabase-сессию/кэш в этом браузере. Поэтому нужно будет войти заново.

## 3. Финальный smoke на чистой базе

1. Открыть `client.html`: каталог пустой, ошибок нет.
2. Создать мастера, заполнить профиль/услуги/работы/график, опубликовать.
3. Создать клиента.
4. Клиент видит мастера и реальные свободные окна.
5. Создать booking, мастер подтверждает, чат открывается.
6. Проверить 90-минутную услугу: соседние 30-минутные точки внутри диапазона недоступны.
7. Отменить booking: открываются только точки, которые всё ещё входят в график.
8. Проверить поддержку client/master ↔ Admin.
9. Завершить booking и оставить отзыв.
10. Проверить logout/login всех трёх ролей.
